# 换机、断线和恢复：看到什么，就处理什么

先保留原批次，不反复点击确认。所有建议仍服从现场授权；本轮未执行实机操作。

| 看到的状态 | 原因与处理 | 恢复后如何验收 |
|---|---|---|
| 等待回应，无重复弹窗 | 正常换机等待；检查舵机独立供电、DATA/GND和型号，工具不能判断实际断电 | 三次回应跨500ms后出现待确认；不会自动写 |
| USB未连接 / 端口改名 | 有可靠序列号会跟随重枚举；否则刷新端口并人工重选 | 连接代次增加，旧预览消失；重新预览 |
| 多个候选 / 型号不明 | 不猜COM名或实体身份；只接一只，核对标签、VID/PID/序列号 | 稳定单候选、实际型号确认，再预览 |
| ROBOTD_ACTIVE / PORT_BUSY | 板端重启后正式服务可能恢复；工具不自动抢总线 | 现场人工交接后，维护独占检查通过 |
| 尚未开始写入就断开 | 旧确认失效 | 重新读/备份/预览，确认剩余差异 |
| 发包后未知 / 中断待核对 | 指令可能已生效，不自动重发 | 核对实物仍是上一只，展开可选维护，勾身份→核对中断及锁状态；重新预览，仅处理剩余项 |
| 修改ID或波特率时断开 | 在旧/新地址与速率只读定位，必要时手工完整扫描 | 核对新读数与原任务，不再发送同一旧任务 |
| HD1910锁未关闭 | 解锁后断电、设置中断；自动重连不擅自写锁 | 人工确认同只后显式恢复relock，记录结果；失败保持未知 |
| Reset Mid应答但MID_NO_EFFECT | 不把ACK当生效；模式/固件/机构位置需核查 | 查位置2048附近与偏移变化，重连不再发0x0B；另行审查后才能新建独立中位步骤 |
| 台架检查中断 | 不续轨迹；保持同连接时可尝试明确卸力并读回，断链不能确认 | 查看任务cleanup/实际扭矩；不能用旧Torque Enable或“连接不上”证明已卸力 |
| 整组某ID失败 | 其他已通过记录保留；缺失/丢参数槽位标修复 | 断电取出该只，单只重新核对/预览/配置，整组再次掉电复核 |
| 旧页面STALE_PLAN / VIEW_ONLY | 修订、连接代次或操作权变化 | 刷新当前状态、必要时接管，重新预览；不重放旧请求 |
| authority目录已占用 | 同一数据库已有后台进程 | 使用原页面或正常停止原后台；不要删除lock绕过 |
| SSH_UNCERTAIN / AGENT_VERSION | 回复丢失、板端离线或代理版本不同 | 等只读恢复、核对板端权威；不自动部署代理或重发apply |
| 代理安装中断 | 部分release保留，current未完成切换 | 先检查现存current/config、包哈希和部分版本；人工审阅后处理，禁止盲目覆盖或删数据库 |

“暂停等待”在空闲时持久暂停只读探测；执行中的按钮先发取消，需等待任务结束后再暂停。关网页不丢进度，关后台后重开从SQLite恢复并清除旧计划。动作取消与断链不保证物理停止；现场需具备可立即断电条件。

建议收集：页面完整错误码、三个连接状态、当前批次/修订/连接代次、导出JSON、实际器件和供电说明。不要提供SSH密码/私钥或认证cookie。JSON记录历史事实，不能代替现场电气测量。
